# 2pop-RD-ES-2p-2a

This is a Mathematica notebook created to analyze the two-population Replicator Dynamics in any 2-player 2-action repeated game with Endogenous Separation. 

It shows the phase portrait of the two-population replicator dynamics with endogenous separation.
